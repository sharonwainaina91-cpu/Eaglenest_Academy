# Academic Resources – PDF Documents

This directory contains downloadable academic resources referenced on the **academics.html** page.

## Required PDF Files

Place the following PDF files in this directory:

1. **curriculum-overview.pdf**  
   Comprehensive guide to CBC implementation across all levels

2. **academic-calendar.pdf**  
   Term dates, holidays, and key academic events for 2026

3. **subject-guide.pdf**  
   Detailed breakdown of subjects offered per level

4. **assessment-policy.pdf**  
   How the school tracks, assesses, and reports learner progress

5. **parent-handbook.pdf**  
   Essential information for parents and guardians

6. **booklist.pdf**  
   Required textbooks and materials for all grades (2026)

## File Naming Convention

- Use lowercase with hyphens (kebab-case)
- Keep filenames descriptive but concise
- All files should be PDF format
- Recommended max file size: 5MB per PDF

## Usage

These files are linked from the "Download Resources" section on the academics page:

```html
<a href="assets/docs/curriculum-overview.pdf" target="_blank">...</a>
```

If a PDF is missing, the link will result in a 404 error. Ensure all files are uploaded before deploying the site.
